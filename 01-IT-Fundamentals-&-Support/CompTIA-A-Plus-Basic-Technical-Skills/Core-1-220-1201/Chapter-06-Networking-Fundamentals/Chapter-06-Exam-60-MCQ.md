## Answer Key & Explanations

**1. C — ShareNet.** ShareNet, released by Novell, was the first PC-based local area network, combining hardware and software components to let offices share resources for the first time.

**2. B — Distributed processing.** Distributed processing splits work between a frontend (data entry, minor processing) and a backend (heavier processing/storage), contrasting with the mainframe-era centralized processing model where everything ran on one machine.

**3. B — Seven.** A Bluetooth piconet supports up to seven connected devices communicating with one central device on an ad hoc basis, with no central access point required.

**4. C — Scatternet.** When two or more piconets link together, with one or more devices bridging them, the result is called a scatternet.

**5. B — MAN.** A metropolitan area network spans a city or large campus — bigger than a LAN, but typically smaller and more centrally managed than a WAN.

**6. B — Fibre Channel.** SANs typically rely on high-speed Fibre Channel connections to deliver fast access even to very large files across dedicated storage devices.

**7. C — Block storage.** Block storage splits files into equal-sized chunks with unique identifiers, contrasting with file storage's folder-and-filename hierarchy, and is the standard model behind most SANs.

**8. B — Wireless access point (WAP).** WLAN clients connect through a WAP, which usually maintains its own wired connection back to a router or switch.

**9. C — Dedicated server.** A dedicated server is assigned to one specific application or service exclusively, such as a web server dedicated only to serving web pages.

**10. A — NIC, cabling (or wireless), client software.** All three are required to turn an ordinary computer into a functioning network client.

**11. B — RJ11.** RJ11 is the connector type used with standard landline telephones, distinct from RJ45's networking role.

**12. D — Four.** RJ45 connectors accommodate four wire pairs (eight wires total), versus RJ11's two pairs.

**13. C — 304 meters.** RG-6 coax supports a maximum distance of roughly 304 meters (1,000 feet), longer than RG-59's 228 meters.

**14. B — Cat 5e.** Cat 5e was the first copper twisted pair cable able to hit 1 Gbps, achieved through physically separated pairs with more twists per foot than Cat 5.

**15. B — 100 meters.** The long-memorized industry standard for twisted pair's maximum run is 100 meters (328 feet), with some newer high-speed standards falling short of that under specific conditions.

**16. B — Plenum-rated.** Plenum-rated (Teflon-type) coating avoids releasing toxic gas when burned and is required by code in air-circulating spaces like above drop ceilings.

**17. C — F-type.** The F-type connector, a named subobjective of Exam Objective 3.2, is the threaded screw-on connector used with RG-6/RG-59 coax for cable television.

**18. C — ST.** The straight tip (ST) connector, developed by AT&T, uses a twist-and-lock mechanism and was historically the most widely used fiber connector.

**19. C — LC.** The Lucent connector (LC), developed by Lucent Technologies, is specifically described as a mini form factor (MFF) connector.

**20. B — Lasers.** Single-mode fiber typically uses lasers as its light source, contrasting with multimode fiber's typical use of LEDs (or increasingly lasers for higher-bandwidth needs).

**21. B — SAN.** A storage area network is purpose-built to hold only networked storage devices, with no client computers or general-purpose servers attached.

**22. C — Who manages the connectivity.** While MANs and WANs can look physically similar, the practical distinction usually comes down to whether a central internal IT organization (MAN) or a public carrier/service provider (WAN) manages the connection.

**23. B — Provides network services while also permitting local access as a workstation.** This flexibility is the defining trait of a nondedicated server, distinguishing it from a dedicated server's single-purpose focus.

**24. C — Uniform block sizes make reads and writes more consistent and efficient.** Because block storage always reads/writes fixed-size chunks, transfers are more efficient and latency is lower than variable-sized file-based access.

**25. B — Client-server.** At 40 employees needing centralized security, client-server's centralized administration and stronger security model fit far better than peer-to-peer's per-machine management.

**26. B — A single cable failure in a star only affects that one device, not the whole network.** Star topology's dedicated per-device cabling isolates failures, unlike bus topology where any break disrupts the shared trunk for everyone.

**27. C — Mesh.** Mesh delivers the best fault tolerance of any topology by giving every device multiple paths to every other device, at the cost of high complexity and cabling expense.

**28. B — It uses a physical star with a logical ring traffic flow.** Despite the name, Token Ring's physical wiring resembles a star, even though data logically travels in a ring pattern from node to node.

**29. B — TCP.** TCP, operating at the Transport layer, verifies that the destination host received all transmitted packets and provides reliable, error-checked end-to-end communication.

**30. B — Presentation.** The Presentation layer handles data formatting, including protocol conversion, compression, translation, encryption, and character-set determination.

**31. B — PCI Express, because using the fastest available bus type prevents the NIC from becoming a bottleneck.** Server NICs are especially prone to bottlenecking if not matched to the fastest available bus type.

**32. A — Full-duplex allows simultaneous send and receive, while half-duplex allows only one direction at a time.** This simultaneous capability is exactly why full-duplex Gigabit Ethernet (1 Gbps) outperforms half-duplex (500 Mbps) by a factor of two.

**33. B — It's the lowest grade offering 10 Gbps throughput, suitable for backbone-level demands.** Cat 6 is the minimum grade recommended for backbone connections between building floors, tied to its 10 Gbps capability.

**34. A — A switch already internally handles the transmit/receive pin crossover that would otherwise be needed.** Switches and hubs handle this internally, which is why a patch (straight-through) cable works fine connecting a host to a switch, while direct host-to-host or like-device connections require a crossover cable.

**35. A — MMF's multiple light paths bounce off the cable walls, weakening the signal faster over distance.** This bouncing behavior is the specific technical reason multimode's usable distance is shorter than single-mode's straight-line light path.

**36. A — SC connectors are latched, making accidental disconnection without releasing the latch far less likely.** This latching mechanism is SC's defining advantage over ST's simpler twist-and-lock design.

**37. C — VLAN.** VLANs let an administrator logically segment computers on one physical switch into isolated networks without new cabling — exactly the described scenario.

**38. A — Broadcasts are addressed to everyone by definition, so switches must forward them to all ports.** Even though switches intelligently direct normal traffic, broadcast traffic's very nature requires it to reach every connected device.

**39. A — Routers break up broadcast domains; switches (and bridges) break up collision domains.** This is the precise functional distinction between the two device types' effects on domain segmentation.

**40. B — A single PoE switch can power multiple devices at once, whereas each injector only serves one endpoint device.** For a ten-AP deployment, a PoE switch's ability to power multiple endpoints from one device is the deciding practical advantage.

**41. B — Peer-to-peer; this is expected, since each workstation manages its own accounts and passwords.** Without a domain controller centralizing authentication, each peer-to-peer workstation independently manages access, requiring separate credentials per machine.

**42. B — Run a new cable from the workstation to the central switch.** Star topology's design makes adding a workstation straightforward — just a single new cable run to the existing central switch, unlike bus or ring's more disruptive processes.

**43. A — A single break anywhere along the trunk cable.** Bus topology's well-documented weakness is that any break in the shared trunk cable disrupts the entire segment, matching the described intermittent total outages.

**44. A — Layer 3 added its header first, then Layer 2 added its header after.** OSI encapsulation proceeds top-down during transmission (Layer 7 down to Layer 1), meaning the Layer 3 (Network) header is added and encapsulated **before** the Layer 2 (Data Link) header wraps around it — so at the point of transmission, Layer 2's header is the outermost, added **last**, just before the frame hits the wire.

**45. B — Client-server, because peer-to-peer's lack of centralized administration will not scale to their growth and security needs.** Given the planned 200-user scale and centralized-policy requirement from day one, client-server's centralized security and administrative model is the only realistic fit.

**46. C — Mesh (used at the WAN level, not necessarily fully meshed at every LAN).** Mesh topology, and the routers that navigate it, is specifically well-suited to connecting multiple WAN sites with redundant path options.

**47. C — Layer 7 (Application).** HTTP data, sitting on top of the already-stripped Ethernet/IP/TCP headers, represents the Application layer payload — the actual content the user's application is exchanging.

**48. A — CSMA/CD's contention-based method inherently produces more collisions as the number of simultaneously transmitting devices increases.** This is the well-documented scalability weakness of CSMA/CD on busy shared segments.

**49. C — Layer 2 (Data Link) / access-method behavior at Layer 1–2.** The CSMA/CD-vs-CSMA/CA distinction is a media access control behavior rooted in the Data Link (and Physical) layers, changing based on whether the connection is wired Ethernet or wireless.

**50. A — Nondedicated servers can serve as both a workstation and a server, reducing the number of machines needed.** For a small, budget-constrained office, this dual-purpose flexibility directly reduces hardware costs compared to a dedicated-only approach.

**51. A — The NIC should have been installed in the faster PCI Express slot to avoid becoming a bottleneck.** This exactly matches the guidance to always use the fastest available bus type, especially critical for servers.

**52. A — Whether a crossover cable, not a patch cable, was used for the direct host-to-host connection.** Direct host-to-host connections specifically require a crossover cable; using a patch cable instead would prevent communication.

**53. A — Cat 6's 10 Gbps rating is only guaranteed up to 55 meters; beyond that, performance degrades.** At 60 meters, this run exceeds Cat 6's 55-meter ceiling for 10 Gbps performance, explaining the degradation.

**54. A — A signal/compatibility mismatch, since MMF and SMF use fundamentally different light propagation and are not interchangeable at the equipment level.** Multimode and single-mode fiber are not simply interchangeable; equipment and cable type must match for a functional connection.

**55. A — A hub; it should be replaced with a switch, which forwards traffic only to the intended port.** The all-ports-repeat, collision-prone behavior described is a textbook hub symptom, resolved by upgrading to a switch.

**56. A — A PoE injector, since only a single endpoint device needs power.** With only one device needing power, an injector is the more cost-effective choice over a full PoE switch.

**57. B — VLAN.** VLANs are specifically designed to logically isolate traffic (like guest Wi-Fi from corporate traffic) on shared physical switch hardware without additional switches.

**58. A — QoS.** QoS directly addresses this scenario by allowing administrators to prioritize latency-sensitive VoIP traffic over general network traffic.

**59. A — Port mirroring.** Port mirroring is specifically designed to copy traffic to a monitoring port without taking the original connected device offline.

**60. A — A screened subnet (formerly DMZ), connected via a third firewall port.** This scenario is the textbook use case for a screened subnet, hosting a public-facing server while maintaining some separation from the fully private network.
