## Video/Display — Image Problems

| Symptom | Cause | Fix |
|---|---|---|
| Burnt-out bulb | Projector lamp end-of-life | Replace bulb (after it cools) |
| Fuzzy image (projector) | Out of focus | Autofocus, onscreen menu, or manual focus ring |
| Fuzzy image (LCD) | EM interference, loose cable, unsupported resolution | Remove interference source, reseat cable, adjust resolution/scaling |
| Sizing issues | Resolution too high (tiny icons) or too low (oversized icons) | Adjust resolution in Display Settings |
| Distorted image | Resolution doesn't match native aspect ratio (16:9, 16:10) | Set resolution back to native |
| Distorted image (non-resolution) | Failing display unit | Power cycle, factory reset, or replace |
| Display burn-in | Ghost image baked into panel; OLED still vulnerable | Replace monitor (no fix) |
| Dead pixel | Pixel never lights up | Replace monitor (no fix) |
| Stuck pixel | Pixel always lit | Try toggle utility (e.g., JScreenFix) or gentle pressure; else replace |
| Flickering screen | Refresh rate ≤60 Hz | Raise refresh rate (Display Settings > Advanced Display) |
| Flickering screen (hardware) | Failing backlight or inverter | Replace backlight/inverter |
| Flashing on/off | Backlight, loose cable, or unsupported resolution | Check cable, change resolution, reinstall driver |
| Incorrect color (LCD) | Failing controller board | Replace monitor |
| Incorrect color (CRT) | Unwanted magnetism | Degauss via onscreen menu |
| Dim image | Failing backlight or brightness setting | Adjust brightness; replace backlight if unresolved |

## Video/Display — Other Issues

|---|---|

## Mobile Devices — Power and Heat

| Symptom | Fix |
|---|---|
| Works plugged in, not on battery | Disconnect battery from motherboard, wait, reconnect |

## Mobile Devices — Damage and Malware

| Concept | Detail |
|---|---|
| Liquid damage (laptop, keyboard only) | Usually salvageable |
| Liquid damage (laptop, reaches ports) | Harder to clean, lasting port issues possible |
| Significant liquid damage | Disassemble, clean with demineralized water + lint-free cloth, dry fully |
| IP rating first digit (0–6) | Solid/dust resistance |
| IP rating second digit (0–8) | Moisture resistance |
| IPX | X = untested for that category |

| Suspected water damage steps | Power off, remove case/SIM/battery, dry, air-dry 48h or rice method |
| Damaged port fix | Replace port (usually = motherboard or full device) |
| 4 antimalware app classes | Antivirus, antispyware, antispam, software firewall |
| 5-step malware removal | Identify → Quarantine → Remediate → Schedule scans/updates → Educate user |
| Mobile malware vectors | Malicious apps, OS vulnerabilities, suspicious links, unsecure networks |
| Jailbreaking | iOS; removes Apple restrictions; illegal in some countries (copyright) |
| Rooting | Android equivalent of jailbreaking |

## Impact Printers

| Symptom | Cause | Fix |
|---|---|---|
| Faded/light characters | Worn ribbon | Adjust printhead distance or replace ribbon |
| Fade dark→light across line | Slipping ribbon-advance gear | Replace gear |
| Blank line (consistent) | Printhead pin stuck in | Replace printhead |
| Blank line (intermittent) | Broken/loose/shorting cable | Secure/replace cable |
| Dark line (consistent) | Printhead pin stuck out | Replace printhead (don't force pin) |
| Printing noise, no print | Worn/missing/misinstalled ribbon | Reinstall/replace ribbon |
| Garbled characters | Loose cable, wrong driver, bad PCB | Reseat cable, fix driver, or replace PCB |
| Paper jam causes | Obstructed path (perf), stripped gears, wrong paper thickness | Clear obstruction, replace gears, adjust platen |
| Peel-off label jam | Never reverse roller | Realign slowly forward only, power off |
| Carriage motor | Drives printhead back-and-forth |
| Main motor | Advances paper |
| Damaged motor symptoms | Uneven line spacing (main) / scrunched chars (carriage); grinding/squeal if severe |

## Inkjet Printers

| Symptom | Cause | Fix |
|---|---|---|
| Thin blank lines / fading | Dried/clogged nozzles (unused 1–2 weeks) | Replace cartridge |
| Smearing letters | Damaged/holed cartridge | Replace cartridge |
| Fades dark→nothing quickly | Broken priming pump | Replace pump |
| Incorrect chroma / color off | Leaking cartridge, wrong paper, wrong cartridge slot, ink mismatch | Clean cartridges, verify slots, replace cartridge |
| Speckling | Paper dust/adhesive residue (rarely leaking cartridge) | Compressed air cleaning |
| Paper jam | Worn pickup roller or wrong paper texture | Replace roller; use dollar-bill-smoothness paper |
| Multi-sheet pickup | Worn separation pads or paper too smooth/damp | Adjust tension lever, replace pads |
| Paper-feed sensor failure | Rarely fails | Clean; else replace printer |
| Uneven line spacing | Main stepper motor damaged | Replace motor |
| Scrunched characters | Carriage stepper motor damaged | Replace motor |
| No power at all | Failed internal transformer (12V/5V) | Replace printer |
| Refill cartridges | Not designed for it — leaks, wrong ink, void warranty | Don't refill |

## Laser Printers — EP Imaging Process

| Step | Voltage/Detail |
|---|---|
| 1. Processing | Page rendered strip-by-strip in memory |
| 2. Charging | Charging corona applies -600VDC to drum (from HVPS) |
| 3. Exposing | Laser reduces charge to ~-100VDC where it scans |
| 4. Developing | Developing roller (-600VDC) attracts toner to -100VDC areas |
| 5. Transferring | Corona applies +600VDC to paper, pulling toner off drum |
| 6. Fusing | 350°F fuser roller + pressure roller melt/press toner |
| 7. Cleaning | Rubber blade scrapes drum; lamp discharges residual charge |

## Laser Printers — Symptoms

| Symptom | Cause | Fix |
|---|---|---|
| No connectivity | IP misconfiguration, DHCP lease change, subnet change after move | Static IP or DHCP reservation; reconfigure via LCD panel/SSH/software |
| Nothing prints / "processing data" | Out of memory | Power cycle (allow several min on large jobs; 20–30+ min = real issue) |
| Paper jam (feed) | Worn rollers or broken drive gear | Test with tray out + flashlight to distinguish; replace worn part |
| Paper jam (exit) | Worn exit rollers | Replace all exit rollers as a set |
| Paper jam (humidity) | Too damp (>~50%) or too dry (<~25%) | Humidity control, seal paper until use |
| Paper jam (static) | Missing/damaged static-charge eliminator strip | Replace strip |
| Blank page | Empty/low toner, wrong refill toner, forgotten sealing tape | Replace/check cartridge, remove tape |
| Blank page (drum has image, paper doesn't) | Damaged/missing transfer corona | Replace corona wire/roller |
| Blank page (corona fine) | Failed HVPS | Replace HVPS |
| All-black page | Charging unit not charging drum | Replace toner cartridge; else HVPS |
| Vertical white lines | Foreign matter (toner) on transfer corona | Clean with supplied brush |
| Vertical black lines | Groove/scratch in EP drum, or dirty charging corona | Replace drum/cartridge, or clean corona |
| Image smudges off (thumb test) | Fuser not heating (bad lamp) | Replace fuser or lamp |
| Repeating smudge pattern | Dent/cold spot in fuser heat roller | Replace fuser assembly/heat roller |
| Ghosting/echo images | Broken cleaning blade or bad erasure lamps | Replace toner cartridge first, then erasure lamps |
| Garbage — readable words, no sense | Wrong driver or page-description language (PCL/PostScript) | Correct driver/PDL setting |
| Garbage — wavy lines/dot patterns | Bad formatter board | Replace formatter board |
| Finishing issues (staple/hole punch) | Jam or out of staples | Clear jam, restock |

## Print Job Management

| Concept | Detail |
|---|---|
| Print queue order | First-come-first-served unless priority configured |
| Job with error | Blocks all jobs behind it; cancel/restart to clear |

| Test page | Prints from printer's own memory; bypasses spooler formatting |

| Test page garbled | Printer or driver issue |
| Paper size (US) | Letter = 8.5" × 11" |

| Wrong page orientation symptom | Cut-off right side or bottom |
| Wrong paper size symptom | Squeezed/smaller output than expected |
| Tray misconfigured | Not recognized, or output truncated |

## Ingress Protection (IP) Rating Quick Reference

| Digit | Range | Meaning |
|---|---|---|
| 1st | 0–6 | Solid/dust resistance |
| 2nd | 0–8 | Moisture resistance |
| X | — | Untested for that category |
| 7 | Moisture | 1m depth, up to 30 min |
| 8 | Moisture | Greater depth/time, per manufacturer spec |
| Waterproof minimum | 7 | Below 7 = water-resistant only, not waterproof |
