Lab Highlights

  • OverTheWire : Bandit

    Bandit wargame levels were completed to master remote server environments. This practical lab provided extensive Linux CLI navigation experience, handling complex file permissions, custom SSH keys, automated bash scripting, and tracking hidden privilege escalation vectors efficiently across systems.

  • Wireshark PCAP Analysis

    Wireshark was utilized to analyze critical malware network traffic captures. This analysis focused on reconstructing attack timelines, isolating command and control communications, detecting DNS anomalies, extracting malicious files, and identifying network indicators of compromise.

  • Cisco Packet Tracer Labs

    Cisco Packet Tracer was configured to build advanced enterprise network topologies. This engineering process involved separating complex corporate VLANs, configuring OSPF routing protocols, implementing strict access control lists, and deploying secure network address translation.

  • Windows Client Labs

    VMware workstations were deployed to harden virtual Windows client operating environments. Deep focus was directed toward establishing secure Group Policy configurations, managing local user account permissions, auditing system security log events, and managing storage settings.
